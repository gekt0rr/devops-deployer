# DevOps Deployer 🚀

### Автоматизированный деплой инфраструктуры через контейнеры

Этот проект позволяет в пару команд разворачивать инфраструктуру с помощью Docker и Ansible.  
Просто указываете репозиторий с конфигурацией — и контейнер делает всю магию за вас!

## 🔹 Как это работает?

1. Контейнер запускается и скачивает ваш репозиторий с конфигурациями.
2. Выполняет Ansible-плейбук или другие скрипты.
3. Возвращает результат выполнения.
